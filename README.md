# Luxury Downloader

A simple and lightweight CLI application installer for Linux.

Luxury Downloader automatically detects your Linux distribution and uses the appropriate package manager to install applications.

## Features

- Automatic Linux distribution detection
- Supports Debian/Ubuntu-based and Arch-based distributions
- Supports APT and Pacman
- Architecture detection
- Automatic sudo handling
- System update option
- Install multiple applications at once
- Install all supported applications
- Detects already installed applications
- Clean and simple CLI interface
- Centralized application registry
- Easy to add new applications

## Supported Applications

| Application | Debian / Ubuntu | Arch |
|---|---|---|
